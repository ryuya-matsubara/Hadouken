# Hadouken Battle ⚡

プレイヤー1 vs プレイヤー2 のターン制対戦Webアプリ。1台の端末で交互に操作する「パス＆プレイ」方式です。攻撃を当てた方が勝ちます。

## あそび方

1. `index.html` をブラウザで開く。
2. プレイヤー1がアクションを選択（相手に見えないように画面を渡す）。
3. 続いてプレイヤー2がアクションを選択。
4. 両者の選択後、バトルシーンで結果が再生される。
5. 勝負が決まれば勝者を表示、決まらなければ次のターンへ。

## ルール

- 1ターンに1アクションを実行する。
- 先にプレイヤー1、次にプレイヤー2がアクションを選ぶ。
- アクション選択時以外は、自分と相手の選択が見えないようになっている。
- 攻撃が命中した方の勝ち。

## アクション

| アクション | 消費エネルギー | 効果 |
|---|---|---|
| 🔵 チャージ | +1 | エネルギーを1溜める |
| 💥 ブラスト | -1 | 相手がチャージ中なら命中。ガードで防がれる。ブラスト同士は相打ち |
| 🛡️ ガード | 0 | ブラストを防ぐ（波動拳は防げない） |
| 🌀 波動拳 | -3 | 波動拳同士なら相打ち、それ以外は必ず命中 |

- エネルギーは最大 **3** 個（🟠 で表示）。
- 消費エネルギーが足りないアクションは選択できません。

## 判定表

| P1 \ P2 | チャージ | ブラスト | ガード | 波動拳 |
|---|---|---|---|---|
| **チャージ** | 続行 | P2勝ち | 続行 | P2勝ち |
| **ブラスト** | P1勝ち | 相打ち(続行) | 続行 | P2勝ち |
| **ガード** | 続行 | 続行 | 続行 | P2勝ち |
| **波動拳** | P1勝ち | P1勝ち | P1勝ち | 相打ち(続行) |

※「相打ち」は勝負がつかず、次のターンへ続行。

## 技術

- 依存ライブラリなしの単一 HTML ファイル（HTML + CSS + Vanilla JS）。
- ビルド不要。`index.html` を開くだけで動作します。
